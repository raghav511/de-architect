# No API key in the browser: AI only through Claude Code on the Mac
- The app no longer stores or uses an AI API key: any page on the same web address could read it. The coach, the live mock interviewer and grading now run only through Claude Code on your Mac (or AI is off).
- A key saved by an older version is deleted the first time this version opens, on every device.
- Profile › AI no longer has a key field, and the coach's photo button is gone (photos needed a key).

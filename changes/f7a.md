# F7 roll-out: integrated week steps in s01–s04
- Modules 1 to 4 now have five short steps each in their week, like Kafka: design it, read and fix a real bug, run it on the platform, lead it, and with AI.
- The fix exercises are quiet wrong-data bugs from each week: an hour window that counts a row twice, a partition overwrite that deletes later days, a salted join that loses rows, and an incremental load that misses late rows.
- Weeks without a simulator challenge open their design problem instead.
